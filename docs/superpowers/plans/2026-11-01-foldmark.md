# Foldmark : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** un plugin wordpress.org en PHP pur qui ajoute une variation « FAQ » à
`core/accordion` et publie un `FAQPage` JSON-LD construit depuis son contenu.

**Architecture :** quatre classes. `Foldmark_Editor` déclare l'attribut et les
variations côté serveur. `Foldmark_Faq_Extractor` lit un arbre `parse_blocks()`
et renvoie des paires question/réponse. `Foldmark_Graph` transforme un `WP_Post`
en nœuds schema.org (nettoyage, déduplication, filtres). `Foldmark_Plugin`
branche les hooks, met le graphe en cache par requête et l'imprime dans `wp_head`.
Aucun JS, aucun asset, aucune option.

**Tech Stack :** PHP 7.4+, WordPress 6.9+, PHPUnit 9.6 + `wp-phpunit` +
`yoast/phpunit-polyfills`, WPCS 3, Plugin Check, DDEV.

**Spec :** `docs/superpowers/specs/2026-11-01-foldmark-design.md` (à lire avant
toute tâche).

## Global Constraints

- Slug, text domain, dossier : `foldmark`. Préfixes : `foldmark_`, `Foldmark_`, `FOLDMARK_`.
- `Requires at least: 6.9`, `Requires PHP: 7.4`, `Tested up to:` version courante de WP (7.1 au 2026-11-01).
- Licence GPL-2.0-or-later ; `LICENSE` = texte GPLv2 (`Version 2, June 1991`).
- Code, commentaires, chaînes sources et messages de commit en anglais. Traduction française livrée à la 1.0.
- Rien dans le markup sauvegardé, aucun filtre `render_block` qui modifie le HTML, aucune option en base, aucun appel réseau, aucun asset.
- Pas de `load_plugin_textdomain()` sauf si la tâche 6 prouve qu'il n'y a pas d'autre moyen.
- Aucune fonction de traduction avant `init`.
- Toute valeur d'attribut est vérifiée (`is_array()`, `is_scalar()`) avant usage.
- Ne jamais éditer `composer.json` / `composer.lock` à la main : `composer require --dev …`, `composer config …`.
- Commits sur la branche `feat/foldmark-1.0`, jamais sur `main`, sans ligne `Co-Authored-By`.

## Review Focus

1. **Réponse qui contient `</script>` ou `<!--`** : le JSON-LD ne doit jamais fermer la balise script. Test : tâche 5, `test_output_cannot_break_out_of_script_tag`.
2. **Pattern synchronisé qui s'inclut lui-même** (directement ou via un autre) : pas de récursion infinie, les questions sont lues une fois. Test : tâche 3, `test_self_referencing_synced_pattern_terminates`.
3. **Attribut corrompu à la main** (`"foldmark":"faq"`, `{"type":["faq"]}`, `{"type":null}`) : ignoré sans notice. Test : tâche 3, `test_malformed_attribute_is_ignored`.
4. **Deux accordéons FAQ sur la page avec une question commune** : un seul `FAQPage`, question émise une fois. Test : tâche 4, `test_duplicate_questions_across_accordions_are_merged_once`.
5. **Item incomplet** (titre vide, panneau vide ou ne contenant qu'une image) : item ignoré ; aucun item valide = aucune sortie. Test : tâche 4, `test_faq_without_valid_item_produces_no_node`.
