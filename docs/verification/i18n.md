# Vérification de la traduction française (2026-11-01)

Banc : WordPress 7.1.4, site en `fr_FR`, aucun `load_plugin_textdomain()` dans le plugin,
aucun fichier `foldmark-*` dans `wp-content/languages/plugins/`.

| Contrôle | Résultat |
|---|---|
| Titre de la variation `foldmark/accordion` avec `languages/foldmark-fr_FR.mo` | « Accordéon » |
| Même contrôle, `.mo` retiré de la copie installée | « Accordion » |
| Description de la variation FAQ | « Questions et réponses publiées comme données structurées FAQ. » |
| `is_textdomain_loaded( 'foldmark' )` | oui |

Décision : le `.mo` embarqué (déclaré par `Domain Path: /languages`) est chargé par le
chargement juste-à-temps de WordPress. Il est livré dans le paquet. Un pack de langue
publié plus tard par translate.wordpress.org dans `wp-content/languages/plugins/`
prendra le relais.
